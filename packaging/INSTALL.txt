REQUIREMENTS
  - The Long Drive on Steam, BETA branch:
    Steam > Library > right-click The Long Drive > Properties > Betas > choose "beta"
  - Everyone in a session must run exactly the same RevaMP version (the game refuses a mismatch and says so).
  - No other mod loader in the game folder (remove an old TLDLoader/ModLoader install first).

INSTALL (Windows)
  1. Steam > right-click The Long Drive > Manage > Browse local files.
  2. Copy EVERYTHING from this zip into that folder (winhttp.dll must sit next to TheLongDrive.exe).
  3. Start the game. Its main menu now has a Mods button between Settings and Exit, and Page Up shows the overlay in
     the top-left corner with the version (@VERSION@) and the frame rate.

INSTALL (Linux / Steam Deck, Proton)
  Same as Windows, then: Steam > The Long Drive > Properties > General > Launch options:
      WINEDLLOVERRIDES="winhttp=n,b" %command%

UPDATING FROM AN EARLIER RevaMP
  Close the game, then copy everything from this zip over the old files (say yes to replace). Nothing else to do:
  your saves and settings stay. Everyone in the session must update - an older version cannot join.

PLAYING TOGETHER
  Open the game's own Multiplayer menu (in the pause menu or on the main menu; F11 in game).
      Host: load or start your world, then press Host. A password is optional.
            Your Steam friends then see your game in their Multiplayer menu. No port forwarding (Steam relay).
      Join: click a friend who is hosting, then Join (type the password if the game has one).
      Your game loads the host's world. The host's machine owns the save; joining never touches your own saves.
  In the menu while playing: the players, their ping, Mute, and (for the host) Kick. Leave / Stop hosting.
  Text chat: Enter (or the game's multiplayer chat key). Escape closes it.
  Voice: hold the game's "Voice chat" key (Settings > Controls; K if it is not bound) to talk - nearby players
         hear you (60 m). Hold O to talk to every player, wherever they are (Settings > Revamp > Multiplayer >
         Talk to everyone key).
         Uses the microphone chosen in Steam (Steam > Settings > Voice). Push to talk / open mic / off and the
         voice volume are in Settings > Revamp.

KEYS
  F11          Multiplayer menu (also the game's own Multiplayer button)
  Page Up      performance overlay on/off (hidden at start)
  Ctrl+Insert  bug report (see below)
  Scroll Lock  session marks: a note on this moment (also /mark <note> in chat)
  Ctrl+F9      record a replay; press again to stop
  Ctrl+F10     watch the latest replay
  None of them is a key the game uses. Change them in Settings > Revamp > Keys (the cinematic camera has no key until
  you set one there) or in BepInEx\config\tldrevamp.core.cfg, section [Keys] (created on the first start).
  With the game's Dev Mode on, F1 still opens its developer menu; its other Dev Mode keys are unbound until you set
  them in Settings > Revamp > Dev Mode keys.

SOMETHING WENT WRONG?
  Right after it happens, press Ctrl+Insert (either Ctrl), write what went wrong if you like and press Enter. Or type
  /bug and a short note in the chat (it is never sent as chat). That saves the bug report as
      <game folder>\BepInEx\tldrevamp-feedback\TLDRevamp-bug-<date>-<time>.zip
  A report contains your note, the game's recent state, the performance and network numbers, the mod's numeric
  settings, your hardware models (CPU, GPU, RAM, OS) and snapshots of the car you sit in (or the nearest one), the
  item you look at or hold and the parts near you. When you host or play alone it also holds your newest autosave (a
  world save). Screenshots, raw log files, player names and file paths are left out, and your own note is cleaned
  before it is saved.
  To include what you did before the bug in a multiplayer game, turn on "Record actions for bug reports"
  (Settings > Revamp > Multiplayer; off unless you turn it on).
  A smaller TLDRevamp-report-<date>-<time>.zip is saved next to the bug zip. KEEP both zips on your own computer:
  the bug zip can hold your world. Do not attach them to a GitHub issue (issues are public) and do not upload them
  anywhere else. Describe the bug and when it happened; if a file is needed, it will be asked for privately.

UNINSTALL
  Delete winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and the BepInEx folder from the game folder.

MOD CATALOG AND JOINING
The Mods button (main menu, between Settings and Exit; also in the pause menu) opens the mod list: All mods and
Installed tabs, a search, a sort, and Install (or Update), Disable / Enable and Remove on each mod. Changes take
effect at the next start. Mods you installed by hand show "By hand".
The live mod catalog is the list of installable releases. Downloads must match its DLL SHA-256.
When joining with missing mods, Install or Install all downloads matching files from the catalog.
The host never sends files. Restart the game, then join again. Hand-installed mods load as usual;
replace those copies by hand. Copy list includes names, versions, source links and mods to remove.
